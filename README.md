# Pocket Sweets Studio（掌心甜點研究所）

> 結合 **LLM Wiki 知識庫架構** 與 **法式復古微縮童話屋美學** 的微縮甜點主題網站專案。

## 專案核心方向

1. **微縮甜點知識與教學**：介紹微縮甜點比例尺、製作材料、工具、擬真技法及完整製作過程。
2. **互動式甜點探索**：提供甜點圖鑑、作品分類、即時搜尋、個人收藏與個人製作紀錄（Craft Log）。

## 專案目錄結構

- `AGENTS.md`：本專案最高開發與知識庫維護規範（AI 代理必讀）。
- `raw/`：不可變原始資料層（原始筆記、文章、材料規格、視覺靈感）。
- `wiki/`：由 AI 協助維護的互聯 Markdown 知識庫，含目錄 `wiki/index.md` 與操作日誌 `wiki/log.md`。
- `src/`：網站應用程式原始碼（頁面、元件、設計系統 `tokens.css`、JSON Schema 與互動腳本）。
- `assets/`：網站靜態圖片與視覺資源。

## 目前專案狀態

- **階段**：基礎架構與規範建立完成（Architecture & Schema Initialized）。
- **下一步**：開始累積第一批 `raw/` 原始資料、編譯核心 `wiki/` 條目（材料／工具／範例甜點），以及實作首頁與圖鑑頁面的 HTML/CSS/JS 原型。
